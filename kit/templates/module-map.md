# 모듈 지도

모듈을 나누는 네 질문: ① 업무 용어로 설명되는가 ② 자기만의 외부 자원이 있는가 ③ 바뀌는 이유가 하나인가 ④ 에이전트가 한 번에 읽을 만한 크기인가.

| 모듈 | 업무 책임 (한 문장) | 맞닿는 이해관계자 | 소유 데이터 | 공개 창구 |
|---|---|---|---|---|
| agent | 요청을 이해하고 모듈에 일을 나눈다 (판단과 위임만) | SH-U01 | 대화 기록 (체크포인터) | `run(...)` |
| <모듈> | <…> | <SH-…> | <…> | `<모듈>/api.py` |

의존 방향: `serving → agent → modules → contracts → platform` (`.importlinter`가 강제)
