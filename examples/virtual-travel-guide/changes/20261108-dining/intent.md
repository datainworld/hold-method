# Intent: 식당 추천

작성: 여행자 A · 프로필: lite · 상태: accepted

## 문제
여행 중 점심·저녁 식당을 고를 때, 동행자의 식사 조건을 매번 메뉴판에서 확인하느라 시간이 걸린다.

## 원하는 결과
도시와 끼니를 말하면, 식사 조건을 지키는 식당 후보 3~5곳을 영업시간과 함께 받는다.

## 이해관계자
- 발안: SH-U01 여행자 A
- 영향 대상: SH-U02 동행자 B (식사 조건의 주인), SH-S02 가상 장소 API (식당 검색)

## 영향 모듈 (추정)
dining (새 모듈), agent (도구 추가)

## 제약
동행자 B는 채식이다. 고기와 생선이 든 메뉴 중심의 식당은 제외한다.

## 뷰
생략: 사용자의 업무 흐름(식당을 고르는 행동) 자체는 바뀌지 않음

## 열린 질문
- 육수처럼 보이지 않는 재료에 고기·생선이 든 경우도 제외하는가? → **답: 제외한다** (여행자 A, 동행자 B 확인)
- 장소 API에 재료 정보가 없으면 어떻게 하나? → **답: "확인 필요"로 표시하고 결과에는 남긴다**
