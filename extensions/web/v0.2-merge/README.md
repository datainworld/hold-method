## 편입의 전제

1. 1차 실증이 끝나고 회고가 열렸다.
2. 회고가 R14~R18마다 유지·수정·삭제를 판정했다(근거: 마찰 기록, `web-measurement.csv`). **유지 판정이 난 규칙만** 본문에 들어간다.
3. 실행 시점 훅(`--with-guard`)은 마찰 기록에서 에이전트가 실제로 선을 넘은 사례가 있을 때만 편입한다. 없으면 HARDENING.md로 남기거나 삭제한다.
4. 편입에도 적대적 리뷰(8장 개정 절차 6)를 거친다. 훅을 포함하면 4차 재공격을 이때 한다.

## 편입하지 않아도 되는 것

확장은 지금 상태로 계속 쓸 수 있습니다. 편입은 "방법론의 일부로 승격"할지의 결정이지, 사용 가능 여부의 결정이 아닙니다.
